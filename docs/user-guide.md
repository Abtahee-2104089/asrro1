# User guide

## Visitors

Use the main navigation to explore ASRRO's research, events, people, media, and publications. Project and alumni directories include filters, while the global search surface finds content across major public categories. Membership and public event forms explain eligibility before submission.

## Applicants

Submit the membership form with academic and payment details. The application remains pending until an executive reviewer approves or rejects it. Approved applicants receive a permanent ASRRO UUID and gain access to member features.

## Members

The dashboard shows membership status, UUID, profile completion, digital membership card, eligible events, registrations, attendance, and notifications. Profile changes are limited to fields the member is allowed to maintain.

## Executive committee

Executive users receive modules based on their assigned role. Member operations cover application review, status changes, and search. Event operations cover event setup, registrations, exports, and attendance. Committee, content, project, and report areas support the organization's ongoing work.

## Finance roles

The president, vice president, financial secretary, and organizing secretary can access detailed finance views. Other roles only see summaries when explicitly permitted. Period controls switch between monthly, quarterly, and yearly reporting.

## Super administrators

Administrators manage roles, website sections, social/contact information, brand assets, gallery content, and theme settings. Role enforcement is always performed in backend functions, not only in the dashboard. Outbound email remains visibly marked as unconfigured until an organization-owned provider is connected.

## Accessibility and mobile use

All core actions are keyboard reachable, visible focus is preserved, and motion reduces when the operating system requests it. The dashboard sidebar becomes a mobile sheet, and dense datasets switch to stacked cards or horizontally scrollable regions on narrow screens.
